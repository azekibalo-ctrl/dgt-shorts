DGT Shorts

Gizlilik Politikası

Son güncelleme: 26 Kasım 2026

Kapsam

Bu politika, DGT Shorts uygulamasının ("Uygulama") Google hesap verilerini nasıl kullandığını açıklar. Uygulama, proje sahibinin kendi bilgisayarında çalışan kişisel bir otomasyon aracıdır ve yalnızca proje sahibinin YouTube kanalına (Dünya Gözüyle Türkiye) video yüklemek için kullanılır.

Erişilen veriler

Uygulama Google OAuth üzerinden yalnızca youtube.upload iznini ister. Bu izinle yalnızca video yükleyebilir ve yüklediği videonun başlık, açıklama ve gizlilik ayarlarını belirleyebilir. Kanalın diğer içeriklerini, yorumları, aboneleri, e-postaları veya başka hiçbir Google verisini okumaz.

Verilerin saklanması

Google'ın verdiği erişim anahtarı (token) yalnızca proje sahibinin bilgisayarında yerel bir dosyada saklanır. Hiçbir sunucuya gönderilmez, üçüncü taraflarla paylaşılmaz ve satılmaz.

Kişisel veri

Uygulama izleyicilerden veya başka kullanıcılardan kişisel veri toplamaz. Çerez, analiz veya reklam takibi kullanmaz.

Google API Hizmetleri

Uygulamanın Google API'lerinden aldığı bilgileri kullanımı, Sınırlı Kullanım (Limited Use) şartları dahil olmak üzere Google API Hizmetleri Kullanıcı Verileri Politikası'na uygundur. Uygulama YouTube API Hizmetlerini kullanır; YouTube Hizmet Şartları ve Google Gizlilik Politikası geçerlidir.

Erişimi iptal etme

Verilen izin her zaman Google hesabı güvenlik ayarlarından geri alınabilir.

İletişim

Sorularınız için GitHub üzerinden ulaşabilirsiniz.

English

Privacy Policy

Last updated: November 26, 2026

Scope

This policy explains how the DGT Shorts application ("the App") uses Google account data. The App is a personal automation tool that runs on the project owner's own computer and is used solely to upload videos to the project owner's own YouTube channel (Dünya Gözüyle Türkiye).

Data accessed

The App requests only the youtube.upload scope via Google OAuth. With it, the App can upload videos and set the title, description and privacy status of the videos it uploads. It does not read any other channel content, comments, subscribers, email or other Google data.

Data storage

The access token issued by Google is stored only in a local file on the project owner's computer. It is never sent to any server, shared with third parties or sold.

Personal data

The App does not collect personal data from viewers or any other users. It uses no cookies, analytics or ad tracking.

Google API Services

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The App uses YouTube API Services; the YouTube Terms of Service and the Google Privacy Policy apply.

Revoking access

Access can be revoked at any time from the Google account permissions page.

Contact

For questions, please reach out via GitHub.
